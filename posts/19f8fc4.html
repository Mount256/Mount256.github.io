进行式和终止式

发表于2026-07-11|更新于2026-07-13|音乐和声学
|总字数:1.1k|阅读时长:3分钟|浏览量:

许多音乐教程网站上都会给出乐谱和对应的音频，但一般情况是乐谱和音频是分离的：乐谱的图片，音频是独立的播放器，不方便维护。不少电子教程只给出乐谱范例而没有音频，不能直观给读者带来声音上的感受，因此引入abcjs以及自带的播放器是有必要的。这里给出一个示范。

进行式

  • 正格进行（Authentic progression）：“属—主”的五度倾向性是和声最基础的关系，因此V—I进行使用极多。
X:3 T:I - V - I C: M:4/4 L:1/4 Q:1/4=150 V:S clef=treble V:T clef=bass %%score [ (S A) (T B) ] K:C V:S %%MIDI program 0 [EGc]4 | [GBd]4 | [EGc]4 | V:T %%MIDI program 0 C,4 | G,4 | C,4 |
  • 变格进行（Plagal progression）：“下属—主”的进行。
X:2 T:I - IV - I C: M:4/4 L:1/4 Q:1/4=150 V:S clef=treble V:T clef=bass %%score [ (S A) (T B) ] K:C V:S %%MIDI program 0 [EGc]4 | [FAc]4 | [EGc]4 | V:T %%MIDI program 0 C,4 | F,4 | C,4 |
  • 顺功能进行：在I—IV—V—I进行中，和声从IV进行到V，不稳定性逐渐增强，张力逐渐积累，然后解决到I，顺应“属—主”倾向性，紧张感一次性得到释放，效果相当舒服。这种“慢准备、快解决”的模式更自然、更符合功能逻辑。
X:1 T:I - IV - V - I C: M:4/4 L:1/4 Q:1/4=150 V:S clef=treble V:T clef=bass %%score [ (S A) (T B) ] K:C V:S %%MIDI program 0 [EGc]4 | [FAc]4 | [GBd]4 | [EGc]4 | V:T %%MIDI program 0 C,4 | F,4 | G,4 | C,4 |
  • 反功能进行：V没有顺应“属—主”倾向性直接解决到I，而是先进行到了IV，使张力先泄掉了一部分，然后才以较弱的倾向性解决到I，总体上造成了“快准备、慢解决”的结果，不符合古典和声的口味。

终止式

收拢性终止

落在主和弦上的终止式称为收拢性终止，一般也简称终止式，收束感较强，一般标志着乐思的结束，相当于句号或感叹号。

  • 正格终止（Authentic cadence）：乐句结束的“属—主”正格进行，以V—I最为典型，V也可换成导三和弦、导七和弦等其他属功能和弦。它是用的最多的一种终止，力量比较强，让听众有明确的结束感。
    • 完全正格终止/复式正格终止：如果前面再加上下属功能组和弦，如IV—V—I、ii—V—I，三个功能组均出现，用到了调内所有的音，即构成完全正格终止。
  • 变格终止（Plagal cadence）：IV—I，即从下属功能组进行主和弦的终止式。它的使用不如正格终止频繁，但在教会唱诗中格外多见，所以又叫教会终止、阿门终止，有一种平静、安详、甜美的感觉。
    • 小变格终止：与变格终止的区别在于用到的是小下属和弦，即iv—I。
  • 补充终止/扩充终止：在乐句、乐段或全曲末尾，于明确终止之后，再额外添加一段短小的终止作为“尾巴”。教会唱诗常在诗篇结束后增加“阿门”两字，和声用了IV—I，就是典型的补充终止。其它常用的补充终止还有vi—I、vii°—I、IV—V—I、ii—V—I等。

开放性终止

不落在主和弦上的终止式就是开放性终止，一般也称半终止，收束感较弱，多表示乐思暂时停顿，相当于逗号。

  • 半终止（Half cadence）：使用不稳定和弦收束，如V、IV，给人乐曲没有结束、只是暂时停顿的感觉，经常用在上半句或开放性乐段的末尾。若用在乐曲结束处，能产生戛然而止、悬而未决、意犹未尽的效果，作用类似文末的问号或省略号。
  • 阻碍终止（Interrupted cadence）/伪终止（Deceptive cadence）：在终止式里用不那么稳定的vi、IV、iii等和弦替代主和弦， 以V—vi最为典型，就像把预期的“终止”过程意外打断，让音乐延续下去，起到推迟终止、扩展乐段的作用。这种模式在乐句中叫做阻碍进行（Interrupted progression）。
